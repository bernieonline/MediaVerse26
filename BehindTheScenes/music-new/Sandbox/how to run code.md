# How to Run Code

## Source Code Location

- **GitHub**: Source code is stored in the GitHub repository
- **Local**: `D:\MediaVerse1.0`

---

## Steps to Launch the Application

### 1. Start Claude Code

Open a terminal and run:

```
claude
```

### 2. Open a Terminal

Open a separate terminal window for running commands. In VS Code you can use `` Ctrl+` `` to toggle the integrated terminal, or open a standalone Command Prompt / PowerShell window.

### 3. Activate the Virtual Environment

In your terminal, run:

```
D:\MediaVerse1.0\BehindTheScenes\venv\Scripts\activate
```

You will know the venv is active when `(venv)` appears at the start of your command prompt.

### 4. Launch the Application

Navigate to the project directory and run the entry point:

```
cd D:\MediaVerse1.0\BehindTheScenes\BehindTheScenes\music-new\Sandbox\MediaPlayerPy
python Framework.py
```
