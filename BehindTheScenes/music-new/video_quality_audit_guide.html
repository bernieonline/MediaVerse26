Video Quality Audit — How It Works

A plain-language guide to understanding the report and making decisions about your video library

What the Tool Does

The audit scans a folder of video files and attempts to identify files that have been degraded relative to their original source — typically a Blu-ray disc. Degradation usually happens when someone re-encodes the video to save space, artificially increases the frame rate, or strips out the high-quality audio track.

The tool does not play the files or analyse the actual picture quality pixel-by-pixel. Instead it reads the technical metadata embedded in each file using MediaInfo, then applies a scoring model based on known patterns that indicate re-encoding or quality loss.

Only 1080p files are evaluated. 4K, 720p, and SD files are skipped.

How the Scoring Works

Each file receives a numeric quality concern score. Points are added whenever a suspicious signal is detected. The more points, the more likely the file has been degraded. A score of zero does not guarantee a perfect file — it means no red flags were found in the metadata.

Frame rate / Interpolation

Checks whether the frame rate has been doubled or artificially raised from a standard cinema rate (24/25/30 fps). Up to 50 points.

Re-encode detection

Looks for software encoder fingerprints (x264, x265, HandBrake, FFmpeg). A genuine disc remux has no encoder tag. Up to 30 points.

Bitrate & compression

Low bitrate for the codec type suggests heavy compression. Measures both raw Mbps and bits-per-pixel-per-frame (bpppf). Up to 50 points.

Audio quality

Checks for a lossless audio track (TrueHD, DTS-HD MA, FLAC, PCM). Lossy-only audio (AC-3, AAC, MP3) is a downgrade signal. Up to 15 points.

Severity Bands

Critical ≥ 60 Multiple serious signals — confirmed frame-rate change, very low bitrate, or re-encode with heavy compression. Strong candidate for replacement. Re-rip from disc or source a new copy.
High 35–59 Likely degraded. May look acceptable on a small screen but will show artefacts on a large display at normal viewing distance. Worth replacing if the disc is available.
Medium 20–34 One or two genuine concerns. Often a competent encode that sacrifices some quality for file size. May be perfectly watchable. Investigate before sourcing a replacement.
Low < threshold Minor signals only. Likely a good-quality file. Probably fine to keep.
Clean No significant issues detected at the configured threshold. No action needed.

Understanding the Report Columns

ColumnWhat it meansWhat to look for
Bitrate Mbps The video stream data rate in megabits per second. A genuine 1080p Blu-ray remux is typically 20–40 Mbps. Below 10 Mbps for AVC or 6 Mbps for HEVC is a concern. Below 6/3.5 Mbps is a serious concern.
FPS Frames per second of the video stream. If the original source rate was different, it appears below in red. Films are shot at 23.976 or 24 fps. A value of 47.952 or 48 is a double — almost certainly artificially interpolated ("soap opera effect").
Codec The video compression format: AVC (H.264) or HEVC (H.265). Neither codec is inherently bad, but HEVC at the same bitrate delivers better quality. The key is bitrate relative to codec — see thresholds above.
Audio The primary audio track format. TrueHD, DTS-HD MA, FLAC, PCM = lossless (good). AC-3 (Dolby Digital), AAC, MP3 = lossy (acceptable on encodes, a downgrade on remuxes).
GB File size in gigabytes. A 2-hour 1080p Blu-ray remux is typically 20–50 GB. A high-quality encode might be 8–15 GB. Below 4 GB for a feature film is a strong compression signal.
bpppf Bits per pixel per frame — a normalised measure of how much data is allocated to each pixel in each frame, independent of resolution and frame rate. A genuine Blu-ray remux is typically ≥ 0.30. Below 0.12 is flagged; below 0.08 is a serious concern. This metric is particularly revealing when frame rate is elevated — a file at 48 fps has half the data per frame compared to the same bitrate at 24 fps.
Score The total quality concern score from all signals combined. Use the severity bands above as your guide. Sort by Score descending to prioritise your review queue.
Issues Detected A plain-language description of every signal that contributed to the score. Read these carefully before deciding to replace a file — some issues are more serious than others even at the same score.

Key Signals Explained

CONFIRMED FRAME-RATE CHANGE (up to +50 points)

MediaInfo found a FrameRate_Original field that differs from the stream's current frame rate. This is definitive proof the frame rate was altered after the source was encoded — almost always artificial interpolation. This is the most reliable signal the tool produces.

SUSPECTED INTERPOLATION (up to +30 points)

The frame rate is an exact ×2 or ×2.5 multiple of a standard cinema rate (e.g. 47.952 fps = 23.976 × 2). No original rate tag was recorded, so this is inferred rather than confirmed, but the pattern is highly suspicious for films.

Re-encoded source (+20 points)

The file contains an encoder library tag such as x264 or x265. A genuine Blu-ray remux is a direct copy of the disc stream and carries no such tag. This signal alone does not mean bad quality — many excellent encodes exist — but combined with low bitrate or high CRF it is significant.

High CRF value (+5 to +20 points)

CRF (Constant Rate Factor) is the quality setting used when encoding. Higher = more lossy. The thresholds used are CRF ≥ 20 for AVC and CRF ≥ 24 for HEVC. A CRF below the threshold still adds a small number of points since any lossy encode is a step down from a remux.

Lossy audio only (+8 to +15 points)

No lossless audio track (TrueHD, DTS-HD MA, FLAC, PCM) was found. For Blu-ray sourced content, the original disc almost always contains a lossless track. Its absence typically means the file was transcoded from a lower-quality source, or the lossless track was stripped to save space.

Making Decisions — A Practical Guide

Step 1 — Start with Critical files

Sort by Score descending. Any file at Critical (≥ 60) almost certainly has a real problem. Look at the Issues column — if you see CONFIRMED FRAME-RATE CHANGE or Very low bitrate combined with a re-encode signal, that file should be replaced.

Step 2 — Check the bpppf value

bpppf is the most nuanced metric in the report. A file might show an acceptable headline bitrate (e.g. 12 Mbps) but if the frame rate has been doubled to 48 fps, each frame actually contains only half that data — the bpppf will reveal this. A bpppf below 0.10 on a 1080p film is almost always evidence of either heavy compression or frame interpolation.

Step 3 — Don't automatically distrust encodes

Not all encodes are bad. A file encoded with x265 at CRF 18, 12 Mbps, with a DTS-HD MA audio track, at 23.976 fps, is a perfectly good copy. It will appear in the report (re-encode signal adds points) but the score will be modest. The Issues column will make this clear — look at what the actual concerns are, not just the score number.

Step 4 — Cross-check file size and duration

The GB column is a quick sanity check. A 2-hour film at 4 GB has been heavily compressed. Compare against the stated bitrate — if they don't match (the report flags this as a File size/bitrate mismatch), the metadata itself may be unreliable, which makes all other measurements less trustworthy for that file.

Step 5 — Use the filter bar to focus

The All Flagged Files table has a filter box. Type a codec name, an issue keyword (e.g. interpolat, HandBrake, TrueHD), or part of a filename to narrow the list. The table columns are also sortable — sorting by bpppf ascending is particularly useful for finding the worst files regardless of headline bitrate.

Limitations

  • Metadata only — the tool cannot see actual compression artefacts, banding, or noise. A file with terrible visible quality but accurate metadata will score lower than a visually clean encode that happens to carry an encoder tag.
  • False positives on legitimate encodes — any file that was intentionally transcoded (e.g. a high-quality Remux→HEVC conversion) will be flagged for the re-encode signal regardless of the result quality. Read the Issues column in full.
  • Variable bitrate files — MediaInfo reports average bitrate. A VBR file might average 15 Mbps but have scenes encoded at 4 Mbps. The per-scene quality cannot be assessed from metadata alone.
  • Sports and action content — elevated frame rates (50/60 fps) are normal for live sports. The frame-rate flags are calibrated for film content. Sports content will accumulate points that don't reflect genuine degradation.
  • Score is additive, not weighted — a file with many minor signals can outscore a file with one catastrophic signal. Always read the Issues column rather than relying on the number alone.
